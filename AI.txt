Q3: What is MCP server? 
Ans: Introduced by Anthropic. A connector between an AI and external data sources, files, or tool like Jira, sharepoint/wiki. There are lot of open-source MCP servers. MCP is an open-source standard so No AI Lock-in like only chatgpt or any other. 
Github copilot intelliJ: MCP only used in Agent Mode,
Click on :Configure Tools->Add More Toold->mcp.json->start mcp server
{
  "servers": {
    "atlassian-jira": {
      "url": "https://atlassian.com"
    }
  }
}
